# الشعار

علامة «مزوّد» صامولة سداسية، وفي وسطها علامة ✓ تعني أن المزوّد موثّق.

| الملف | متى يُستخدم |
| --- | --- |
| `mazood-mark.svg` | النسخة الأساسية الملوّنة: صامولة كهرمانية `amber` وقلب كحلي `navy`. تشتغل على الخلفيات الفاتحة والداكنة. |
| `mazood-mark-navy.svg` | لون واحد، كحلي `#0F2A44`. للطباعة بلون واحد، والأختام، والفواتير. |
| `mazood-mark-white.svg` | لون واحد، أبيض `#FFFFFF`. فوق الصور، وفوق الخلفيات الكحلية أو الكهرمانية. |
| `mazood-app-icon.svg` | أيقونة التطبيق: مربع كحلي بزوايا دائرية، وفيه العلامة الملوّنة. |

- **المساحة الآمنة:** اترك حول العلامة فراغًا لا يقل عن ربع عرضها من كل جهة.
- **أصغر مقاس:** ٢٤ بكسل على الشاشة، و٨ مم في الطباعة.
- **ممنوع:** تدوير العلامة، أو تغيير ألوانها، أو إضافة ظل أو تدرّج لها، أو وضع النسخة الملوّنة فوق صورة مزدحمة.
- **كلمة «مزوّد»** تُكتب بخط IBM Plex Sans Arabic بوزن 700، وبالشدّة دائمًا، وتوضع على يسار العلامة في السطر العربي. الشكل الكامل للشعار موجود في مكوّن Logo.
