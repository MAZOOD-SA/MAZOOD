## ٣. إعطاء صلاحية لمبرمج أو سحبها

**الكود (GitHub):**
1. ادخل github.com بحساب الشركة، وافتح منظمة `mazood-sa`.
2. **للإضافة:** People ← Invite member ← اكتب اسم حسابه أو إيميله ← اختر الدور **Member** (مو Owner).
3. **للسحب:** People ← جنب اسمه ← Remove from organization. يتنفذ فورًا.

**نصيحة:** خلّ صلاحية «Owner» لك ولشخص ثاني تثق فيه بس، عشان لو ضاع وصولك ما تنقفل المنصة.

إضافة موظفين لفريق الإدارة (التوثيق، وخدمة العملاء، والمالية) تكون من لوحة الإدارة نفسها، وتجي في المرحلة ٣ و٦.

## ٤. توظيف مبرمج وتسليمه المشروع

المشروع مكتوب بحيث أي مبرمج يكمّل من الملفات بدون ما يرجع لك أو لمحادثاتنا:

1. **وش تطلب في المبرمج:** خبرة في TypeScript وReact (أو React Native). وميزة إذا يعرف Node.js وPostgreSQL.
2. **أعطه صلاحية GitHub** (القسم ٣).
3. **قل له يقرأ بالترتيب:** `CLAUDE.md`، ثم `README.md`، ثم `PLAN.md`. فيها كيف يشغّل المشروع ووين وصلنا ووش الجاي.
4. **أول مهمة تختبره فيها:** يشغّل المشروع على جهازه ويشغّل الاختبارات (`pnpm test`)، ويرسل لك صورة الشاشة. إذا ما قدر يسويها بيوم من الملفات بس، قل لنا: معناها التوثيق ناقص.

## ٥. استخدام Claude Code لأول مرة

Claude Code هو المساعد اللي يكتب الكود ويحدّث الملفات. تقدر تطلب منه بكلامك العادي.

**أول مرة:**
1. افتح claude.ai/code وادخل بحساب الشركة.
2. اربطه بـ GitHub واختر مستودع `mazood-sa/mazood`.
3. اكتب طلبك بالعربي، وانتظر. هو يقرأ `CLAUDE.md` لحاله ويمشي عليه.
4. قبل أي شغل كبير، بيعرض عليك خطة. اقرأها، ووافق أو عدّل.

**أمثلة لطلبات بسيطة:**
- «وش آخر شي انبنى في المنصة؟ لخّصه لي بنقاط.»
- «غيّر نص زر "أرسل الرمز" إلى "أرسل رمز التحقق".»
- «وش الأسئلة اللي تنتظر قراري في PLAN.md؟»
- «اشرح لي كيف المصنع يرفع طلب، خطوة بخطوة.»
- «ابنِ المرحلة ٣ من PLAN.md.»

**نصائح:**
- طلب واحد واضح أفضل من خمس طلبات في رسالة.
- إذا تغيّر الموضوع، افتح محادثة جديدة.
- لا ترسل له كلمات مرور أو صور هويات أو بيانات عملاء حقيقية.
