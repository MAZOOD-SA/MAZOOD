# إجراء: تأكيد هوية فرد يدويًا

**المسؤول:** موظف التوثيق (أو المدير العام، أو المالك).
**متى:** لين يجهز الربط مع «نفاذ»، لما يحتاج فرد تأكيد هويته (مثلًا الإعداد «الفرد ما يطلب إلا بعد تأكيد هويته» مفعّل).
**متى ترفعه للمدير العام:** لو الاسم أو الرقم ما يطابق، أو الشخص رفض يبيّن هويته.

## الخطوات

1. **لوحة الإدارة ← العملاء**، وصفّي «ينتظرون تأكيد الهوية»، أو ابحث بالاسم أو الجوال.
2. افتح صفحة العميل. رقم الهوية يطلع كامل لك (واطلاعك ينسجل).
3. تأكد بطريقة معتمدة من المدير: مثلًا الشخص يبيّن هويته الأصلية في مكتب الشركة، أو مكالمة فيديو.
4. لو الاسم والرقم مطابقين: **«أكّد الهوية»**، واقرأ التنبيه، وأكّد.

## انتبه (نظام حماية البيانات الشخصية)

- **لا تطلب** من العميل يرسل صورة هويته في واتساب أو إيميل.
- **لا تنسخ** رقم الهوية برا اللوحة، ولا تصوّر الشاشة.
- التأكيد ينسجل باسمك، فلا تأكّد وأنت مو متأكد.
