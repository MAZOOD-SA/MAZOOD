# إجراء: تعديل إعداد في المنصة

**المسؤول:** المدير العام أو المالك. **العمولة: المالك بس.**
**متى ترفعه للمالك:** أي تعديل يأثّر على الفلوس (العمولة، والفترة المجانية، والرسائل النصية لأن لها تكلفة)، أو يأثّر على كل الطلبات الجديدة.

## الخطوات

1. **لوحة الإدارة ← الإعدادات**.
2. عدّل القيمة، واضغط **«احفظ»** اللي تحت القسم نفسه.
3. لو طلعت رسالة خطأ، القيمة برا الحدود المسموحة. صحّحها.
4. اكتب في قناة الفريق وش غيّرت وليش. (التعديل ينسجل تلقائيًا: مين، ومتى، ومن كم لكم.)

## انتبه

- **الطلبات القديمة ما تتأثر** بأغلب الإعدادات (مثل سياسة الإلغاء: تنحفظ مع الطلب وقت القبول).
- إذا ما تعرف وش يسوي الإعداد، لا تغيّره. اسأل المدير.
