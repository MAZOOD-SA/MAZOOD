# إجراء: إخفاء منتج مخالف

**المسؤول:** خدمة العملاء (أو المدير العام، أو المالك).
**متى:** بلاغ عن منتج، أو لاحظت منتج ممنوع أو وصفه مضلل أو سعره وهمي أو فيه رقم جوال أو رابط.
**متى ترفعه للمدير العام:** لو المنتج ممكن يكون مخالف للنظام (مواد ممنوعة مثلًا)، أو لو نفس المصنع تكررت مخالفاته (يمكن يحتاج إيقاف).

## الخطوات

1. **لوحة الإدارة ← السوق ← المنتجات**، وابحث باسم المنتج أو المصنع.
2. اضغط **«أخفِ المنتج»**.
3. اكتب السبب بوضوح، مثل: «الوصف فيه رقم جوال. التواصل داخل المنصة بس. احذف الرقم وأظهر المنتج من جديد.»
4. أكّد. المنتج يختفي من السوق فورًا، والسبب يوصل للمصنع.

## الإرجاع

لو المصنع عدّل المنتج أو كان الإخفاء بالغلط: صفّي «مخفي لأنه مخالف»، واضغط **«رجّع المنتج»** مع السبب. يرجع **مخفي**، والمصنع يظهره بنفسه.
