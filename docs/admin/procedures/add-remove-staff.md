# إجراء: إضافة موظف أو سحب صلاحيته

**المسؤول:** المدير العام (لكل الأدوار ما عدا المدير العام)، والمالك (لكل الأدوار ومنها المدير العام).

## إضافة موظف

1. تأكد إن عنده رقم جوال **غير مسجّل** في المنصة كمصنع أو مزوّد.
2. **لوحة الإدارة ← الموظفين**: اكتب الاسم والجوال، واختر الدور، واضغط «أضف موظف».
3. قل للموظف: «ادخل المنصة برقم جوالك ورمز التحقق». يوصل للوحة مباشرة.
4. أعطه خطة أول أسبوع: [`../onboarding.md`](../onboarding.md).

**اختر أقل دور يكفي شغله.** موظف خدمة العملاء ما يحتاج يشوف الهويات.

## سحب الصلاحية (موظف ترك العمل أو تغيّر دوره)

1. **الموظفين** ← «أوقف الحساب» تحت اسمه. يطلع من المنصة فورًا، وأي رابط مستند فتحه يبطل.
2. لتغيير الدور: أضفه من جديد بنفس الرقم والدور الجديد.

سوّها **في نفس يوم** ترك الموظف للعمل.

## أول مالك (مرة وحدة عند الإطلاق)

المالك الأول ما يُضاف من اللوحة. يضيفه المبرمج من الخادم بالأمر:

```
pnpm api:add-staff -- <رقم الجوال> owner "<الاسم>"
```
