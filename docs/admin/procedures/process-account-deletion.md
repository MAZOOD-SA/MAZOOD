# إجراء: تنفيذ طلب حذف الحساب

**المسؤول:** المدير العام أو المالك.
**المدة المستهدفة:** خلال ٧ أيام من الطلب (المحامي يأكد المدة النظامية، البند ٤٤ في `docs/legal/brief-for-lawyer.md`).
**متى ترفعه للمالك:** لو صاحب الحساب عليه مستحقات، أو عنده نزاع قانوني، أو طلب الحذف جا من غير صاحب الحساب.

## وش يصير عند الحذف (قرار المالك، 23 نوفمبر 2026)

| ينمسح | يبقى (النظام يطلب حفظه) |
| --- | --- |
| رقم الجوال، والاسم، ورقم الهوية، وملف الهوية | الطلبات والفواتير، وسجل الإجراءات، والرسائل، بدون الاسم |
| الدخول ينقفل والجلسات تنتهي | الاسم التجاري للمزوّد أو المنشأة (بيانات منشأة تظهر في الفواتير) |

**ما يتراجع عنه.**

## الخطوات

1. **لوحة الإدارة ← طلبات الحذف**.
2. اقرأ السبب. لو واضح إنه ما يبي يحذف فعلًا (مثلًا يبي يغيّر رقمه)، تواصل معه أول.
3. **«نفّذ الحذف»**، واقرأ التنبيه، وأكّد.
4. لو طلع «عنده طلب جاري أو بلاغ مفتوح»: ما ينحذف لين يخلص. اضغط **«ارفض»** واكتب له وش يسوي، مثل: «عندك طلب جاري. بعد ما يكتمل أو تلغيه، اطلب الحذف من جديد.» السبب يطلع له في «حسابي».
