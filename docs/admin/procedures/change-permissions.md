# إجراء: تغيير صلاحيات الأدوار

**المسؤول:** المالك بس.
**متى:** لما تبي دور يشوف قسم ما يشوفه (مثلًا المالية تشوف البلاغات)، أو تشيل قسم عن دور.

## الخطوات

1. **لوحة الإدارة ← الصلاحيات**.
2. لكل قسم، اختر الأدوار اللي تشوفه (المالك عنده كل شي دائمًا).
3. **«احفظ الصلاحيات»**. ينطبق فورًا على كل الموظفين، والتغيير ينسجل.
4. «رجّع الافتراضي» يرجّع الجدول في `admin-guide.md`.

## انتبه

- **المقفولة ما تتغيّر:** تغيير العمولة، وتغيير الصلاحيات، وإضافة الموظفين. هذي قرارات المالك (CLAUDE.md).
- **رقم الهوية والمستندات بيانات حساسة** (نظام حماية البيانات الشخصية): أعطها بس للي يحتاجها لشغله.
- بعد أي تغيير، خل الموظف يطلع ويدخل، ويتأكد إنه يشوف اللي يحتاجه بس.
