# إجراء: رفض طلب توثيق

**المسؤول:** موظف التوثيق. **يرفعه للمدير العام:** إذا كان السبب اشتباه تزوير أو احتيال.

الفرق بين رفض **مستند** ورفض **الطلب كامل**:

| الحالة | وش تسوي |
| --- | --- |
| مستند واحد فيه مشكلة (صورة غير واضحة، منتهي، رقم مختلف) | ارفض **المستند** بس مع السبب. المزوّد يرفع نسخة جديدة، والطلب يبقى في القائمة. |
| الطلب كله ما ينفع (النشاط ما يناسب أي قسم، أو الشخص غير الصاحب الفعلي للمنشأة) | ارفض **الطلب** من «رفض طلب التوثيق كامل» مع السبب. المزوّد يقدر يعدّل بياناته ويعيد الإرسال. |
| اشتباه تزوير | لا ترفض. ارفعه للمدير العام فورًا، وهو يقرر (ممكن الإيقاف). |

## الخطوات (رفض الطلب كامل)

1. افتح المزوّد من «طلبات التوثيق».
2. في خانة «السبب (يوصل للمزوّد)» اكتب سبب محدد وش المطلوب منه (شوف أمثلة في [`verify-provider.md`](verify-provider.md)).
3. اضغط «ارفض الطلب». يطلع للمزوّد «يحتاج تعديل» مع السبب.
