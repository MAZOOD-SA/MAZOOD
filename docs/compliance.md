# الجاهزية النظامية (الوضع الرسمي للمنصة)

**آخر تحديث:** 22 نوفمبر 2026
**لمين:** المالك والشريك، والمحامي والمحاسب، والمبرمج اللي يستلم.

> **تنبيه مهم:** هذا الملف قائمة تحقق عامة، وما هو رأي قانوني ولا محاسبي. الأنظمة السعودية تتغيّر، فكل بند يُؤكَّد من محامٍ ومحاسب مرخّصين قبل الإطلاق. أي بند ما نحن متأكدين منه مكتوب فيه «يُتحقق منه»، وما نفترض.

## 1. الوضع الحالي

- المنصة حاليًا تحت التطوير وببيانات وهمية. ما فيه فلوس حقيقية ولا بيانات عملاء حقيقية.
- أحد الشريكين عنده **وثيقة عمل حر**. الوثيقة باسم شخص واحد، وهي مناسبة للتجربة فقط، وما تكفي للإطلاق التجاري (الأسباب في القسم 2).
- **قاعدة:** ما نستلم أي مبلغ حقيقي ولا هويات حقيقية قبل ما يكتمل التأسيس (القسم 3) وتنتهي بنود «قبل الإطلاق» في القسم 4.

## 2. ليش وثيقة العمل الحر ما تكفي للإطلاق

| السبب | التفصيل |
| --- | --- |
| باسم شخص واحد | الشريك الثاني ما له وضع قانوني ولا حق مكتوب في المنصة |
| الأنشطة محددة | يُتحقق منه: هل نشاط منصة وساطة إلكترونية داخل أنشطة الوثيقة؟ |
| المدفوعات | بوابات الدفع المرخّصة غالبًا تفضّل سجل تجاري، وبعضها يرفض الأفراد. والحساب البنكي لازم يكون تجاري |
| المتاجر | Apple وGoogle يعطون حساب منظمة للشركات. حساب الفرد يظهر باسم الشخص |
| الفاتورة الموحدة | تحتاج كيان واضح يصدر الفواتير ويتحمل ضريبتها |
| العقود | عقود المصانع والمزوّدين باسم فرد تعني مسؤولية شخصية كاملة عليه |
| البيع لاحقًا | منصة مربوطة بوثيقة شخص ما تنباع ولا تنتقل ملكيتها، وهذا يخالف مبدأ «جاهزية البيع» في `CLAUDE.md` |

## 3. خيارات التأسيس

| الخيار | مناسب لـ | العيب |
| --- | --- | --- |
| وثيقة العمل الحر (الحالي) | تجربة صغيرة بدون فلوس، ومعرفة السوق | ما تنفع للإطلاق التجاري |
| مؤسسة فردية | إطلاق سريع وتكلفة قليلة | باسم شخص واحد، ومسؤوليته مفتوحة، ويصعب بيعها |
| **شركة ذات مسؤولية محدودة (أو مبسّطة)** | **الأنسب:** تحفظ حق الشريكين، وتحدد المسؤولية، وتقبل المدفوعات والمتاجر، وتنباع | تكلفة تأسيس أعلى بقليل |

**التوصية:** نكمل التطوير والتجربة بدون فلوس بوثيقة الشريك، وقبل الإطلاق نؤسس شركة باسم الشريكين عن طريق المركز السعودي للأعمال. **القرار النهائي للمالك والشريك بعد استشارة محامٍ.**

**خطوات مقترحة (تُؤكَّد مع المختص):**
1. توقيع اتفاقية بين الشريكين الآن، قبل التأسيس (القسم 5).
2. اختيار الشكل النظامي مع المحامي (ذات مسؤولية محدودة أو مبسّطة).
3. التأسيس والسجل التجاري بنشاط يغطي المنصات الإلكترونية والوساطة.
4. فتح حساب بنكي باسم الشركة.
5. نقل كل الحسابات المؤقتة (إن وجدت) لاسم الشركة، وتحديث `docs/services.md`.

## 4. قائمة التحقق

الحالة: `[ ]` لم يبدأ، `[~]` جاري، `[x]` تم. **تُحدَّث بعد كل خطوة.**

### أ. الكيان والتراخيص
- [ ] **قبل الإطلاق:** سجل تجاري باسم الشركة ونشاطه يغطي المنصات الإلكترونية والوساطة.
- [ ] **قبل الإطلاق:** اتفاقية شركاء مكتوبة (القسم 5).
- [ ] **قبل الإطلاق:** تسجيل المنصة في «معروف» (وزارة التجارة)، وعرض رقم السجل والرقم الضريبي ووسائل التواصل في الموقع والتطبيق. يُتحقق منه: متطلبات نظام التجارة الإلكترونية الحالية على المنصات الوسيطة.
- [ ] عنوان وطني، وحساب بنكي تجاري باسم الشركة، واشتراك الغرفة التجارية.
- [ ] تسجيل العلامة التجارية (الاسم والشعار) لدى الهيئة السعودية للملكية الفكرية.
- [ ] حجز النطاق (.sa و.com) باسم الشركة.
- [ ] التأمينات الاجتماعية ونطاقات وقوى، عند توظيف أول موظف.

### ب. الضرائب والفوترة
- [ ] **قبل المرحلة 5:** قرار دور المنصة مع المحاسب: وسيط يفوتر عمولته فقط، أو طرف يفوتر المبلغ كامل (سؤال 2 في `PLAN.md`).
- [ ] **قبل الإطلاق:** تسجيل ضريبة القيمة المضافة (إلزامي إذا تجاوز الإيراد 375 ألف ريال، يُتحقق منه)، وتسجيل الزكاة.
- [ ] **المرحلة 5:** الربط مع الفوترة الإلكترونية (فاتورة) في هيئة الزكاة والضريبة والجمارك، واختباره على بيئتهم التجريبية أول.

### ج. المدفوعات (أخطر نقطة)
- [ ] **قبل المرحلة 5:** رأي قانوني: استلام مبالغ المصانع وتحويلها للمزوّدين قد يُعد نشاط مدفوعات يحتاج ترخيص البنك المركزي (ساما). يُتحقق منه، وما نفترض.
- [ ] استخدام بوابة دفع مرخّصة تدعم تقسيم المبالغ، وعدم الاحتفاظ بفلوس العملاء في حساب الشركة قبل الرأي القانوني.
- [ ] سياسة الاسترجاع والإلغاء ومواعيد صرف المزوّدين، مكتوبة وواضحة.

### د. حماية البيانات والأمن
- [ ] **قبل الإطلاق:** الامتثال لنظام حماية البيانات الشخصية (سدايا): سياسة خصوصية، وموافقة صريحة قبل جمع الهوية، ومدة الاحتفاظ، وحق الحذف والتعديل.
- [ ] يُتحقق منه: هل المنصة تحتاج تسجيل كجهة تحكم بالبيانات في المنصة الوطنية لحوكمة البيانات؟
- [ ] **قبل المرحلة 2:** قرار مكان الاستضافة. نقل بيانات الهويات خارج المملكة له شروط، فنفضّل داخل السعودية (سؤال 4 في `PLAN.md`). يُتحقق منه: تنظيم الحوسبة السحابية من هيئة الاتصالات.
- [ ] إجراء مكتوب للإبلاغ عن أي تسريب بيانات للجهات المختصة.
- [ ] ضوابط الأمن السيبراني من الهيئة الوطنية للأمن السيبراني كمرجع.
- [ ] تسجيل اسم المرسل (Sender ID) لرسائل OTP لدى مزوّد رسائل مرخّص (سؤال 5).
- [ ] التحقق من هوية المزوّدين وسجلاتهم عبر جهات معتمدة بعد البداية اليدوية (سؤال 12). الخدمات لها رسوم.

### هـ. الوثائق القانونية (بالعربي أولًا، يكتبها أو يراجعها محامٍ)
- [ ] شروط الاستخدام للمصانع.
- [ ] شروط واتفاقية المزوّد: العمولة، والمسؤولية، وضوابط التوثيق، وإيقاف الحساب.
- [ ] نص يوضح أن المنصة وسيط، وحدود مسؤوليتها عن جودة التنفيذ.
- [ ] آلية النزاعات، والنظام الحاكم، والجهة القضائية.
- [ ] سياسة الخصوصية.

### و. تراخيص المزوّدين (نطلبها عند التوثيق، وتُعتمد في سؤال 8)
كل بند **يُتحقق منه** من الجهة المنظمة، وهذا مجرد مقترح أولي:

| القسم | المستند المقترح |
| --- | --- |
| نقل ومعدات | ترخيص نقل من هيئة النقل، وبطاقة تشغيل المركبة، واشتراطات نقل الأغذية للمبرّد |
| تخليص جمركي | أن يكون مخلصًا جمركيًا مرخّصًا من هيئة الزكاة والضريبة والجمارك |
| أمن وسلامة | ترخيص وزارة الداخلية للأمن، واعتماد الدفاع المدني لمعدات السلامة |
| رمل دفان | ترخيص المقلع من وزارة الصناعة والثروة المعدنية، والاشتراطات البيئية |
| نظافة (كيماويات) | اشتراطات المواد الكيميائية والنقل الآمن لها |
| صيانة وحرف | رخصة بلدية، ووضع العمالة النظامي |

- [ ] مراجعة إدارة مدينة سدير: هل عندها اشتراطات أو شراكة للمنصات اللي تخدم المصانع؟

### ز. التطبيقات
- [ ] **ابدأ بدري:** رقم D-U-N-S للشركة (يأخذ وقت).
- [ ] حساب Apple Developer وGoogle Play باسم الشركة.
- [ ] سياسة الخصوصية برابط، وإمكانية حذف الحساب من داخل التطبيق.

### ح. حماية الشركة
- [ ] تنازل مكتوب عن الحقوق لصالح الشركة من أي مبرمج أو مصمم، وتسجيل الأمر في `docs/licenses.md`.
- [ ] يُدرس: تأمين مسؤولية مهنية وتأمين سيبراني.

## 5. اتفاقية الشركاء: وش لازم تغطي

كتابتها عند محامٍ، لكن النقاط اللي نتأكد إنها موجودة:
1. حصة كل شريك، ومين يضع رأس المال وكم.
2. المهام والصلاحيات، وكيف تُتخذ القرارات (ومنها قرارات المالك في `CLAUDE.md`).
3. أن الكود والعلامة التجارية والنطاق والحسابات ملك للشركة، لا لأي فرد، حتى لو سُجّلت مؤقتًا باسم أحد.
4. خروج شريك أو وفاته أو خلاف: كيف يُقيَّم نصيبه وكيف يُشترى.
5. بيع المنصة أو دخول مستثمر: الموافقات المطلوبة.
6. توزيع الأرباح والمصروفات.

## 6. أسئلة مفتوحة

1. هل الشريكان سعوديان؟ وهل عندهم وظائف؟ (يؤثر على الشكل النظامي المسموح.)
2. رأس المال المتوقع؟
3. هل الإطلاق التجاري قريب، أم الهدف الآن تجربة مع عدد قليل من مصانع سدير بدون فلوس؟
4. هل نشاط الوثيقة الحالية يغطي منصة وساطة؟ (يؤكده المحامي.)

## 7. مين يحدّث هذا الملف

كل ما انتهى بند، يغيّر المالك أو من يكلّفه علامته، ويكتب التاريخ. وما نكتب هنا أي رقم سجل أو رقم ضريبي أو بيانات الشركة. هذي يدخلها المالك في إعدادات المنصة بنفسه.
