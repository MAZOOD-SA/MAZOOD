# مزوّد (Mazood)

منصة B2B تربط مصانع مدينة سدير الصناعية بمزوّدين موثّقين: المصنع يرفع طلب، والمزوّدين يرسلون عروض، والمصنع يقبل عرض واحد، وتوصله فاتورة موحّدة.

من كود واحد يطلع **الموقع** و**تطبيق iPhone** و**تطبيق Android**.

> **الحالة الحالية: المرحلة ١ (نموذج تجريبي).** شاشات المصنع كاملة ببيانات وهمية، بدون خادم. التفاصيل والمراحل الجاية في [`PLAN.md`](PLAN.md).

## المتطلبات على جهازك

- **Node.js 22** أو أحدث
- **pnpm 10** (فعّله بالأمر `corepack enable`)
- للتجربة على الجوال: تطبيق **Expo Go** من App Store أو Google Play

## التشغيل خطوة بخطوة

```bash
pnpm install
```

```bash
pnpm web
```

بعدها افتح الرابط اللي يطلع (عادةً `http://localhost:8081`). في النسخة التجريبية أي رقم جوال سعودي وأي رمز من ٦ أرقام يدخلك.

**على الجوال:** شغّل `pnpm start`، وامسح رمز QR بكاميرا الجوال (iPhone) أو من داخل Expo Go (Android). لازم الجوال والكمبيوتر يكونون على نفس الشبكة.

## الاختبارات (أمر واحد)

```bash
pnpm test
```

الأمر يسوي أربع خطوات بالترتيب، ويوقف عند أول خطأ:

1. يعيد توليد الثيم من `brand/tokens.json`.
2. يتأكد إن ما فيه أي لون مكتوب مباشرة في الكود.
3. يفحص أنواع TypeScript.
4. يشغّل اختبارات Vitest: الهوية، والمبالغ والضريبة، والتنسيق، ومنطق الطلبات والعروض.

## رسم المعرفة (graphify): للمبرمج وللـ Claude Code

المستودع فيه رسم يربط الكود بالوثائق (`PLAN.md` و`docs/`)، وهو في `graphify-out/`. يختصر البحث في المشروع: بدل ما تقرأ ملفات كثير، تسأل الرسم فيرجّع الأجزاء المرتبطة بس. وهو أداة تطوير فقط، ما يدخل في المنتج.

**التثبيت (مرة وحدة)**، ويحتاج Python 3.10 أو أحدث:

```bash
pip install graphifyy
graphify claude install
```

الأمر الثاني يضيف قسم graphify في `CLAUDE.md` وhooks في `.claude/settings.json`. وهما موجودان في المستودع أصلًا، فلا تشغّله إلا لو انحذفا. الـ hooks تستدعي `/usr/local/bin/graphify`، فإذا ثبّتّه في مكان ثاني عدّل المسار في `.claude/settings.json`.

**الاستخدام**

```bash
graphify query "كيف يشتغل الدخول بالجوال؟"      # أسئلة عن المشروع
graphify explain "useStore"                      # شرح عنصر وما يرتبط فيه
graphify path "useStore" "RequestDetails"        # العلاقة بين عنصرين
graphify section "المرحلة 2"                     # نص قسم من ملف Markdown
```

**التحديث بعد كل تعديل على الكود** (مجاني، بدون ذكاء اصطناعي):

```bash
graphify update .
```

بعدها ارفع التغيير على `graphify-out/` مع الـ commit. تغيّر كبير في `graph.json` شي طبيعي لأنه يُكتب كله من جديد كل مرة. وخريطة المشروع التفاعلية في `graphify-out/graph.html`، تنفتح بالمتصفح.

بعد تعديل ملفات Markdown أو الصور، شغّل `/graphify --update` من داخل Claude Code بدل الأمر أعلاه.

## النشر

**المرحلة ١:** الموقع ملفات ثابتة (static). تُبنى بالأمر:

```bash
pnpm build:web
```

والناتج في `apps/app/dist`، ويُرفع على أي استضافة ملفات ثابتة. الاستضافة الرسمية ونشر التطبيقين في المتاجر ما انقرروا للحين، لأنهم يحتاجون حسابات باسم الشركة (شوف `docs/services.md`).

## قواعد لازم تمشي عليها

- **ولا لون مكتوب مباشرة في الكود.** الألوان من `useTheme().colors` فقط، والاختبار يفشل لو لقى `#xxxxxx` أو `rgb(...)`. لتغيير لون: عدّل `brand/tokens.json` و`brand/tokens.css` ثم شغّل `pnpm tokens`.
- **زر accent (كهرماني) واحد بس في كل شاشة**، للإجراء الأهم.
- **المبالغ بالهللة كأرقام صحيحة** (`src/lib/money.ts`). لا تستخدم كسور للفلوس.
- **كل نص في الواجهة** يُكتب في `apps/app/src/i18n/strings.ts` بالعربي والإنجليزي، وبنبرة `BRAND.md`.
- **أيقونة جديدة:** أضفها في `apps/app/src/components/icons.ts` (من Tabler Icons).
- **مكتبة جديدة:** سجّلها مع رخصتها في `docs/licenses.md`.

## هيكل المجلدات باختصار

```
apps/app/          الواجهة: الموقع والتطبيقين (Expo + Expo Router)
  app/             الشاشات (كل ملف = صفحة)
  src/components/  المكوّنات المشتركة (الأزرار، والبطاقات...)
  src/data/        البيانات الوهمية ومنطق الطلبات (يتبدّل بالخادم في المرحلة ٢)
  src/i18n/        النصوص بالعربي والإنجليزي، والاتجاه
  src/lib/         المبالغ والتنسيق
  src/theme/       الوضع الفاتح والداكن
packages/brand/    الثيم المولّد من brand/tokens.json
brand/             ملفات الهوية (المرجع، لا تُعدّل بدون موافقة)
scripts/           أدوات الفحص
docs/              التوثيق
```

التفاصيل الكاملة في [`docs/architecture.md`](docs/architecture.md).
