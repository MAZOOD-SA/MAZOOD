# مزوّد (Mazood)

منصة B2B تربط مصانع مدينة سدير الصناعية بمزوّدين موثّقين: المصنع يرفع طلب، والمزوّدين يرسلون عروض، والمصنع يقبل عرض واحد، وتوصله فاتورة موحّدة.

من كود واحد يطلع **الموقع** و**تطبيق iPhone** و**تطبيق Android**.

> **الحالة الحالية: المرحلة ٢ (الدخول الحقيقي والطلبات).** خادم وقاعدة بيانات، ودخول برقم الجوال ورمز تحقق، والمصنع يكمّل بياناته ويرفع طلبات تنحفظ. العروض والفواتير والتنبيهات تجريبية لين المرحلة ٤ و٥ (وعليها علامة «تجريبي»). التفاصيل في [`PLAN.md`](PLAN.md).

## المتطلبات على جهازك

- **Node.js 22** أو أحدث
- **pnpm 10** (فعّله بالأمر `corepack enable`)
- **Docker** (لقاعدة البيانات). أو PostgreSQL 16 مثبّت على الجهاز، وفيه قاعدتين: `mazood` و`mazood_test`.
- للتجربة على الجوال: تطبيق **Expo Go** من App Store أو Google Play

## التشغيل خطوة بخطوة (أول مرة)

**١. ثبّت المكتبات:**

```bash
pnpm install
```

**٢. شغّل قاعدة البيانات** (تشتغل بالخلفية، وتبقى بعد إعادة تشغيل الجهاز):

```bash
pnpm db:up
```

**٣. جهّز إعدادات الخادم:**

```bash
cp .env.example apps/api/.env
```

بعدها افتح `apps/api/.env` وعبّ `SESSION_SECRET` و`OTP_PEPPER` بقيمتين **مختلفتين**. كل وحدة تولّدها بهذا الأمر:

```bash
node -e "console.log(require('crypto').randomBytes(32).toString('base64url'))"
```

**٤. أنشئ جداول قاعدة البيانات:**

```bash
pnpm db:migrate
```

**٥. شغّل الخادم** (اتركه شغّال في طرفية):

```bash
pnpm api
```

لازم يطلع سطر فيه `Server listening at http://0.0.0.0:3000`. تقدر تتأكد بفتح `http://localhost:3000/health`.

**٦. شغّل الموقع** (في طرفية ثانية):

```bash
pnpm web
```

افتح الرابط اللي يطلع (عادةً `http://localhost:8081`).

## كيف تجرّب

1. اكتب أي رقم جوال سعودي (مثل `0551234567`) واضغط «أرسل الرمز».
2. **الرمز ما يوصل برسالة في التطوير.** يطلع في طرفية الخادم (`pnpm api`) بسطر فيه `[SMS للتطوير فقط] رمز الدخول إلى مزوّد: 123456`.
3. اكتب الرمز. أول مرة يطلب منك بيانات المصنع.
4. ارفع طلب من «اطلب عرض».
5. حدّث الصفحة أو اقفلها وارجع: تلقى نفسك داخل، وطلبك موجود.
6. للتأكد من الصلاحيات: اطلع من «حسابي» وادخل برقم ثاني. ما تشوف طلبات المصنع الأول.

**على الجوال:** شغّل `pnpm start` بدل `pnpm web`، وامسح رمز QR بكاميرا الجوال (iPhone) أو من داخل Expo Go (Android). لازم الجوال والكمبيوتر على نفس الشبكة. التطبيق يتصل بالخادم على نفس الكمبيوتر تلقائيًا (المنفذ 3000). إذا الخادم في مكان ثاني، حط عنوانه في `apps/app/.env`:

```bash
EXPO_PUBLIC_API_URL=http://192.168.1.5:3000
```

> **Safari على الكمبيوتر:** بعض نسخه ما تحفظ الكوكي المحمي (Secure) على `http://localhost`، فتطلع من الحساب إذا حدّثت الصفحة. استخدم Chrome أو Firefox للتطوير، أو جرّب من الجوال.

## الاختبارات (أمر واحد)

قاعدة البيانات لازم تكون شغّالة (`pnpm db:up`)، ثم:

```bash
pnpm test
```

الأمر يسوي خمس خطوات بالترتيب، ويوقف عند أول خطأ:

1. يعيد توليد الثيم من `brand/tokens.json`.
2. يتأكد إن ما فيه أي لون مكتوب مباشرة في الكود.
3. يفحص أنواع TypeScript في التطبيق والخادم.
4. اختبارات **unit**: الهوية، والمبالغ والضريبة، والتنسيق، ورقم الجوال، وقواعد التحقق، ومنطق العروض التجريبية.
5. اختبارات **api** على قاعدة `mazood_test` (يمسحها ويبنيها من جديد كل مرة): رمز التحقق وحدوده، والجلسات وكشف سرقة مفتاح التجديد، والصلاحيات (المصنع ما يشوف طلبات مصنع ثاني)، ورفض المدخلات الغلط، ومنع تعديل سجل الإجراءات.

بدون قاعدة بيانات تقدر تشغّل اختبارات unit بس: `pnpm test:unit`.

## النشر

> الاستضافة الرسمية ما انقررت للحين (سؤال ٤ في `PLAN.md`). هذي الخطوات العامة لأي استضافة.

**الخادم (`apps/api`):**

1. سيرفر فيه Node.js 22، وقاعدة PostgreSQL 16 (يُفضّل خدمة مُدارة فيها نسخ احتياطي).
2. حط كل الإعدادات من `.env.example` في **الإعدادات السرية** للاستضافة (مو في ملف). وفي التشغيل الحقيقي:
   - `NODE_ENV=production`
   - `SMS_PROVIDER`: مزوّد حقيقي. الخادم **يرفض يشتغل** بـ `console` في production.
   - `CORS_ORIGINS`: نطاق الموقع بس (مثل `https://app.mazood.sa`).
   - `TRUST_PROXY=true` إذا الخادم ورا موزّع أحمال.
3. الأوامر:

```bash
pnpm install --frozen-lockfile
```

```bash
pnpm db:migrate
```

```bash
pnpm --filter @mazood/api start
```

4. لازم يكون قدامه HTTPS (من الاستضافة أو موزّع الأحمال). الكوكي المحمي ما يشتغل بدونه.

**الموقع:** ملفات ثابتة تُبنى بالأمر التالي، والناتج في `apps/app/dist` يُرفع على أي استضافة ملفات ثابتة. قبل البناء حط `EXPO_PUBLIC_API_URL` بعنوان الخادم.

```bash
pnpm build:web
```

**التطبيقين:** عن طريق Expo (EAS)، ويحتاج حساب الشركة (شوف `docs/services.md`).

## قواعد لازم تمشي عليها

- **ولا لون مكتوب مباشرة في الكود.** الألوان من `useTheme().colors` فقط، والاختبار يفشل لو لقى `#xxxxxx` أو `rgb(...)`. لتغيير لون: عدّل `brand/tokens.json` و`brand/tokens.css` ثم شغّل `pnpm tokens`.
- **زر accent (كهرماني) واحد بس في كل شاشة**، للإجراء الأهم.
- **كل صلاحية تُفحص في الخادم.** الواجهة تخفي وتظهر للراحة بس، وما يُعتمد عليها. أي مسار جديد يمر على `requireAuth` و`requireRole`، وأي استعلام يتقيّد بمصنع المستخدم من الجلسة.
- **كل مدخل يُفحص بـ Zod** من `packages/shared` في الخادم قبل ما يُحفظ.
- **ولا سر في الكود ولا في التطبيق.** الأسرار في الإعدادات، وأسماؤها في `.env.example`. أي متغير يبدأ بـ `EXPO_PUBLIC_` ينشاف داخل التطبيق.
- **أي تغيير على قاعدة البيانات** بملف ترحيل جديد في `apps/api/prisma/migrations/` (الطريقة في `docs/architecture.md`).
- **المبالغ بالهللة كأرقام صحيحة** (`src/lib/money.ts`). لا تستخدم كسور للفلوس.
- **كل نص في الواجهة** يُكتب في `apps/app/src/i18n/strings.ts` بالعربي والإنجليزي، وبنبرة `BRAND.md`.
- **أيقونة جديدة:** أضفها في `apps/app/src/components/icons.ts` (من Tabler Icons).
- **مكتبة جديدة:** سجّلها مع رخصتها في `docs/licenses.md`.

## هيكل المجلدات باختصار

```
apps/app/          الواجهة: الموقع والتطبيقين (Expo + Expo Router)
  app/             الشاشات (كل ملف = صفحة)
  src/auth/        حالة الدخول
  src/data/        الطلبات من الخادم، والبيانات التجريبية (العروض والفواتير)
  src/lib/         الاتصال بالخادم، والمبالغ، والتنسيق
apps/api/          الخادم (Fastify + Prisma)
  prisma/          شكل قاعدة البيانات وملفات الترحيل
  src/             المسارات، والدخول، والصلاحيات
  test/            اختبارات الخادم
packages/brand/    الثيم المولّد من brand/tokens.json
packages/shared/   قواعد التحقق المشتركة بين التطبيق والخادم
brand/             ملفات الهوية (المرجع، لا تُعدّل بدون موافقة)
docs/              التوثيق
```

التفاصيل الكاملة في [`docs/architecture.md`](docs/architecture.md).
